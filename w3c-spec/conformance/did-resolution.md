# DID Resolution Conformance Matrix (Initial Phase 1 Audit)

**Baseline:** [DID Resolution v1, W3C Candidate Recommendation Snapshot, 06 August 2026](https://www.w3.org/TR/2026/CR-did-resolution-1.0-20260806/). **Audited commit:** `59ef0b027777006924d9aa27009d50097eb217fe`.

The exact baseline is recorded separately from DID Core because DID Resolution evolves independently. This matrix covers the inspected resolver/API surfaces, not an HTTP resolver service.

| ID | Requirement / DID Resolution section | Implementation evidence | Existing test evidence | Status | Notes / follow-up |
| --- | --- | --- | --- | --- | --- |
| DR-001 | Resolution returns `didResolutionMetadata`, `didDocument`, and `didDocumentMetadata` (§4, §9) | `packages/did/src/midnight-did-resolver.ts` (`resolutionEnvelope`) | `midnight-did-resolver.test.ts` success/not-found envelope tests | PASS | Abstract resolve result is distinct from representation result. |
| DR-002 | Successful abstract resolution omits representation `contentType` (§4, §9) | `resolveDIDResolutionResult` returns `{}` metadata on success | resolver success envelope test | PASS | Content type belongs to representation resolution. |
