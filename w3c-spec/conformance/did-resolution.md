## Trust interpretation

A configured indexer/provider response is trusted input to this resolver profile. A stale, unavailable, compromised, or untrusted read does not prove DID absence, deactivation, or transaction finality. `null` is `notFound` only inside the trust assumptions of the configured provider. Applications needing independent state integrity or finality must supply that assurance above this profile; 0.6 provides no light client, state-proof verification, or independent consensus check.
