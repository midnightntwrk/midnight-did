## Trust interpretation

The injected reader's response is trusted input to this package resolver. A stale, unavailable, compromised, or untrusted read does not prove DID absence, deactivation, or transaction finality. Applications needing independent state integrity or finality must supply it above this profile; 0.6 provides no light client, state-proof verification, or independent consensus check.
