# DID Core 1.1 Compatibility Matrix (0.6 Evidence)

**Standards baseline:** [W3C DID Core 1.1 Candidate Recommendation Snapshot, 05 March 2026](https://www.w3.org/TR/2026/CR-did-1.1-20260305/). **Integration base:** `55dde88ce1e451587303b5f4fc388eef4bdb32f5`. **Implementation under test:** the exact clean `git HEAD` printed by `pnpm test:conformance`, not the integration base.

**Overall 0.6 compatibility result: FAIL.** Version 0.6 is a DID Core 1.0-era profile. Its reusable abstract-data, identity, and lifecycle behavior is identified below, but its representations use the DID Core 1.0 context and media types rather than the DID Core 1.1 requirements for `https://www.w3.org/ns/did/v1.1` and `application/did`. The current 1.0 representation tests are therefore recorded as evidence of the incompatibility, not as positive 1.1 representation evidence. The coordinated breaking migration is tracked by [#447](https://github.com/midnightntwrk/midnight-did/issues/447).

DID Core 1.1 remains an audited Candidate Recommendation compatibility target; it does not replace the DID Core 1.0 Recommendation baseline for 0.6. Exact revision evidence comes from clean-tree command output recorded in PR or release evidence; the command runner verifies that the complete lane leaves the recorded HEAD and tracked files unchanged. This lane is not currently run or retained by CI. Immutable external/CI evidence remains tracked by [#446](https://github.com/midnightntwrk/midnight-did/issues/446). Each row keeps the requirement, method text, implementation, and exact test distinct so a broad family label cannot substitute for evidence.
