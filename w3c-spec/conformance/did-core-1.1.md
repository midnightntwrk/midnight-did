# DID Core 1.1 Compatibility Matrix (0.6 Evidence)

**Standards baseline:** [W3C DID Core 1.1 Candidate Recommendation Snapshot, 05 March 2026](https://www.w3.org/TR/2026/CR-did-1.1-20260305/). **Integration base:** `55dde88ce1e451587303b5f4fc388eef4bdb32f5`. **Implementation under test:** the current `git HEAD` printed by `pnpm test:conformance`, not the integration base.

DID Core 1.1 is a separate Candidate Recommendation compatibility target; it does not replace the DID Core 1.0 Recommendation baseline. Exact release evidence is bound to retained command/CI output for an immutable release tag. Each row keeps the requirement, method text, implementation, and exact test distinct so a broad family label cannot substitute for evidence.
