# DID Core 1.1 Compatibility Matrix (0.6 Evidence)

**Baseline:** [W3C DID Core 1.1 Candidate Recommendation Snapshot, 05 March 2026](https://www.w3.org/TR/2026/CR-did-1.1-20260305/). **0.6 starting commit:** `55dde88ce1e451587303b5f4fc388eef4bdb32f5`.

DID Core 1.1 is a separate Candidate Recommendation compatibility target. It does not replace the DID Core 1.0 Recommendation baseline, and the rows below do not claim complete 1.1 compatibility.

| Requirement family                                               | Exact executable evidence                                                                                                                                                                                                                                                                                                                                                                                                   | 0.6 compatibility status          | Boundary                                                                                                          |
