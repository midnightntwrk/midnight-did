# Specification

This section publishes the Midnight DID method specification and the DID method
traits matrix used by implementers and reviewers.

## Documents

- [Midnight DID Method](./midnight-method.md)
- [Midnight DID Traits](./midnight-did-traits.md)

## Canonical files

The published pages are synchronized from the canonical repository files during
the docs build:

- `w3c-spec/midnight-method.md`
- `w3c-spec/midnight-did-traits.md`

## How to use this section

- read **Midnight DID Method** for syntax, document shape, operations, and metadata rules
- use the method spec's resolution media-type table when implementing resolver
  HTTP responses or `resolveRepresentation` support
- read **Midnight DID Traits** for a capability summary against DID method traits
- use the package docs and [repository boundary guide](/development/repository-boundaries) when you need to know where those rules are implemented
