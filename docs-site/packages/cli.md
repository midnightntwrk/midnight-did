# CLI Package

`@midnight-ntwrk/midnight-did-cli` is the user-facing shell and state-machine layer.

## Focus

- shell UX
- CLI API/state machine
- guidance and next-step hints
- orchestration over API and secret storage

## Use it when

- you need a local operator workflow
- you want deterministic, testable command orchestration
- you want to reuse the CLI service layer without committing to the interactive shell

## Main repository paths

- `cli/src/cli-api/`
- `cli/src/shell/`
- `cli/src/api.ts`
- `cli/README.md`
